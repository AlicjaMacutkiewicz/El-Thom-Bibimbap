# VECM and rockets

Well, it doesn't work, because it's not supposed to.

In the folder, you'll find graphs for the best model I managed to create.

As you can see in the graphs, the data is **very** nonlinear, so using VECM is a bit of a misnomer.

--

## Conclusion
It's impossible to fit a linear model to nonlinear data.

VECM is not designed to predict trajectories.
